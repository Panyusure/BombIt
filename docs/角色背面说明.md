# 角色背面朝向

六位可选精灵和未来通灵形态均有独立的透明背面素材。向上移动时显示背面，向下切回正面，左右沿用原朝向；松开按键保持最后朝向。对角输入以实际选中的移动轴决定朝向，碰墙时也可转身，传送带和木马不会强制改变朝向。重生和换关从正面开始。

单双人键位均生效，双方朝向互不影响。选角列表仍为六人，方向变体不会重复出现在菜单。未来通灵前后的背面会随形态切换，保留光晕与守护灵效果。

背面使用与正面相同的角色坐标和碰撞框，只改变显示；各素材单独校准裁切、显示高度与脚底锚点。背面不做左右镜像，尚未加载时自动回退对应正面。背面同样在加载时缓存为512像素纹理，不在每帧重新缩小原图。

## 素材

使用内置 **image_gen**，根据项目现有正面素材生成真正的背面。小天移除了属于正面的项链装饰；通灵守护灵补全后脑甲、背甲、机械脊线和手背。没有覆盖原有正面图片，没有使用CLI。

未来普通背面采用通灵图中本体的造型，靴子改为后跟视角。通灵背面反转前后遮挡关系：翅膀在前、守护灵躯干其次，未来本体在后、被部分遮挡，可见的靴子同样为后跟视角。[未来两形态的修正提示词](../assets/characters/weilai-back-corrections.json)。

最终通灵背面的层次为：**翅膀最前 → 守护灵躯干 → 未来本体最后**。翼根和内侧羽片覆盖部分背甲与上臂。守护灵躯干重做为平整机械背甲、散热口、翼根铰链、后腰连接件，移除正面胸甲和腹甲式的宝石板块。[守护灵最终修正提示词](../assets/characters/guardian-back-corrections.json)。
