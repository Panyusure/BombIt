# BOMBIT MOTION UI · 界面重设计

> 2026-10-18 · 将《Q版泡泡堂》游戏界面统一到 Motion ID 的平面设计语言  
> 预览：[UI 设计板](ui-motion-board.jpg) · [开始界面](ui-motion-menu.png)

## 方向

原本的深蓝夜空底 + 绿色胶囊按钮 + 半透明玻璃卡片，统一替换为 **奶油纸 + 墨色硬边 + 糖果色块 + 错位硬阴影 + 印刷编号** 的 BOMBIT 视觉系统。游戏仍然是同一个游戏，只换了一层更有节奏、更有版面临场感的皮。

## 设计 token

| Token | 值 | 用途 |
|---|---|---|
| Ink | `#141019` | 标题、HUD 报头、边线 |

| Pink | `#FF5E9E` | 2P、对战、通灵 |
| Cyan | `#5CE1F2` | 1P、计时、科技信息 |
| Yellow | `#FFD23F` | 开始按钮、奖励提示 |

字体：`HarmonyOS Sans SC`（中文标题/正文） + `Impact`（数字与英文大标） + `Consolas`（微信息、编号）。

## 页面改造

### 开始界面
- 固定骨架：报头 / 模式 / 1P 精灵 / 2P 精灵 / 技能信息 / 开始按钮，切换模式时不再上下跳动。
- 模式改成三张大色块：选中的卡片反转为墨色，加上 `ON` 贴纸和模式色硬阴影。
- 角色改为六张头部裁切卡，选中项用玩家色（1P 青 / 2P 粉）做硬阴影和 `P1/P2` 角标。
- 底部技能区改成一张完整的黑色海报信息块：大号角色名、技能、说明、Lore、冷却/Q 键都在同一张卡里。
- 顶部加入印刷报头、橙色太阳、笑脸炸弹、场景色点与“对局回放”贴纸按钮。
- 壁纸仍然加载，但降到 7% 作为纸张底纹，不再和文字抢注意力。

### HUD
- 72px 顶部报头换成深墨底、奶油字、模式编号水印和真实的键位提示。
- 玩家状态卡改成奶油色票据：P1/P2 色签、名字、生命、火力/炸弹/速度、手套/护盾/无敌星。
- 悬浮计时/分数变成“奶油外框 + 黑底白字”的小牌，危险时只闪下方小字，不再整块闪烁。
- BOSS 血条改成同样的票据语言，用阶段颜色分段。
- 底部技能条统一成奶油卡：按键帽、技能名、状态、冷却进度 / 通灵六格。

### 关前敌情档案
- 改成一张奶油色档案海报：深色刊头、场景色立绘块、奶油圆形舞台、初次登场/本关提醒贴纸。
- 右侧按“故事 → 行动 → 攻击 → HP”排列；底部新增黑色 MISSION 条，收拢阵容、场景机制、过关目标。
- 开始按钮保持原来的固定命中区，键盘/鼠标/测试都不受影响。

### 暂停 / 结算
- 暂停：奶油卡 + 墨色刊头 + 超大标题 + 三行编号按钮；Esc 继续和点击命中区保持原样。
- 结算：赛果贴纸、颜色随胜负变化（胜利黄 / 失败青 / 平局粉）、数据表、黑色页脚提示标签。
- 修正单人计时拆砖超时仍显示 `WIN` 的问题，现在会正确显示 `LOSE` 并使用冷色赛果。

### 载入页
- 奶油纸张 + 右上橙色太阳 + 弹珠炸弹图标 + 墨色卡片 + 橙色硬阴影。
- 大标题 `Q版泡泡堂 / BOMBIT`，进度条与加载状态沿用原来的启动脚本 ID，不影响加载测试。
