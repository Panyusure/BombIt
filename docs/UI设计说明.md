# BOMBIT MOTION UI · 界面重设计

> 2026-10-18 · 将《Q版泡泡堂》游戏界面统一到 Motion ID 的平面设计语言  
> 预览：[UI 设计板](ui-motion-board.jpg) · [模式选择](ui-motion-menu.png) · [角色选择](ui-motion-spirits.png) · [双人角色选择](ui-motion-spirits-versus.png) · [声音设置](ui-motion-settings.png)

## 方向

原本的深蓝夜空底 + 绿色胶囊按钮 + 半透明玻璃卡片，统一替换为 **奶油纸 + 墨色硬边 + 糖果色块 + 错位硬阴影 + 印刷编号** 的 BOMBIT 视觉系统。游戏仍然是同一个游戏，只换了一层更有节奏、更有版面临场感的皮。

## 页面改造

### 两层开始界面
- **STEP 01 · 模式选择**：一开始只显示模式，不再把角色和技能信息挤在第一屏。三张竖版模式卡占据主视觉，选中的卡反转为墨色，配模式色硬阴影、编号和图形母题；底部主按钮进入精灵选择。
- **STEP 02 · 角色选择**：上方是 680×310 的超大横向动效海报，下方才是一排六张 106×80 的小卡。海报内直接放角色名、技能、说明、Lore、键位/冷却和玩家标签，不再单独开资料面板。
- 海报包含右侧奶油聚光圆 + 厚色环 + 旋转放射、全身体角色、幽灵编号、浮动星、底部滚动跑马灯和玩家色硬阴影；切换角色时做缩放落定 + 奶油闪光。
- 双人模式在角色页顶部提供 1P / 2P 标签，数字 1/2 或点击标签切换玩家；确认 1P 后自动切到 2P，第二次确认开始对战。
- 角色页保留“返回模式”(Esc) 与“对局回放”入口；模式、角色选择在返回菜单时保留，但重新从模式页开始。
- 壁纸仍然加载，但降到 7% 作为纸张底纹，不再和文字抢注意力。

### 声音设置
- 对局回放右侧新增小齿轮入口，打开“声音设置”弹层。
- 两条大滑块分别调整 `音效 SFX` 和 `音乐 MUSIC`，实时显示 0–100% 百分比，拖动时立即生效并写入 `localStorage`。
- `M` 仍然保留全局静音；设置里的百分比在静音解除后继续生效。`Esc`、右上角 ×、点击弹层外或“完成”都能关闭。
- 设置打开时菜单其余输入完全冻结，不会误触模式/角色/开局。

### HUD
- 72px 顶部报头换成深墨底、奶油字、模式编号水印和真实的键位提示。
- 玩家状态卡改成奶油色票据：P1/P2 色签、名字、生命、火力/炸弹/速度、手套/护盾/无敌星。
- 悬浮计时/分数变成“奶油外框 + 黑底白字”的小牌，危险时只闪下方小字，不再整块闪烁。
- BOSS 血条改成同样的票据语言，用阶段颜色分段。
- 底部技能条统一成奶油卡：按键帽、技能名、状态、冷却进度 / 通灵六格。

### 关前敌情档案
- 改成一张奶油色档案海报：深色刊头、场景色立绘块、奶油圆形舞台、初次登场/本关提醒贴纸。
- 右侧按“故事 → 行动 → 攻击 → HP”排列；底部新增黑色 MISSION 条，收拢阵容、场景机制、过关目标。
- 开始按钮保持原来的固定命中区，键盘/鼠标/测试都不受影响。

### 暂停 / 结算
- 暂停：奶油卡 + 墨色刊头 + 超大标题 + 三行编号按钮；Esc 继续和点击命中区保持原样。
- 结算：赛果贴纸、颜色随胜负变化（胜利黄 / 失败青 / 平局粉）、数据表、黑色页脚提示标签。
- 修正单人计时拆砖超时仍显示 `WIN` 的问题，现在会正确显示 `LOSE` 并使用冷色赛果。

### 载入页
- 奶油纸张 + 右上橙色太阳 + 弹珠炸弹图标 + 墨色卡片 + 橙色硬阴影。
- 大标题 `Q版泡泡堂 / BOMBIT`，进度条与加载状态沿用原来的启动脚本 ID，不影响加载测试。

| `index.html` | 页面外框 / 启动加载页 / 画布硬阴影 |
