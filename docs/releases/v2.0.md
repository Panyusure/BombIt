# v2.0 · Agent 接入泡泡堂

本次版本的核心是让 Agent 能完整接入泡泡堂：读取公开局面、决策、提交动作，完成对局并生成可供人类观看的回放。浏览器和 CLI 共用确定性游戏内核，覆盖三种模式、六位角色与十关冒险。

## Agent 操作接口

- 无依赖 Node.js CLI 与逐行 JSONL 协议；等待决策时游戏暂停。
- `serve --memory` 在内存推进，免去每步加锁和重写整个会话；`checkpoint` 显式保存恢复点。
- `batch.steps` 一次提交最多 1024 个动作；`path.path` 提交相邻格路线；`goTo.target` 自动寻路到指定格。
- 支持同时控制双方、可选危险区间提示、请求去重与版本检查；阵亡、换关、换回合、结算时提前返回。
- 提供可运行的参考 Agent 与 DeepSeek 策略源码，均默认使用内存模式。（v2.1 起已移除固定策略示例，Agent 由各自模型自行决策）

```powershell
node cli/bombit.cjs serve --memory
```

完整协议与接入例子见 [CLI 与 Agent 使用说明](../CLI与Agent.md)。内存模式强制终止只能恢复最近检查点；自动寻路不保证避开爆炸，应在危险路段分段观察。

## 人类观看 Agent 对局

- 开始菜单右上角新增「对局回放」，在游戏内选择或拖入本机回放。
- 播放器支持 0.25～16 倍速度、逐帧、动作跳转、进度拖动及换关、阵亡标记。
- 每个动作逐步校验；点击「返回游戏」或按 Esc 保留原来的模式与角色选择。
- 本地文件和 GitHub Pages 均可使用，回放只在本机读取，不上传文件。

## 存档与性能

每局收尾自动校验，只保留 `data/replays/` 中一个 `YYYYMMDD-HHMMSS-agent-mode-character-result-id.replay.json`；角色使用实际 ID，双人按 P1/P2 顺序写成 `xiaonuo-vs-axiu`，会话编号也包含角色。旧回放可用 `tools/migrate-replay-names.cjs --apply` 原地迁移，不保留副本或旧名入口。清除工作存档与单局临时文件，旧会话名只作追溯元数据。临时数据与测试产物统一管理，不逐步保存响应文件。

使用 DeepSeek 十关通关的全部 3231 步，在同一台电脑对比长连接执行：逐步落盘 23.75 秒，内存加批量 5.07 秒；请求数 3231 → 15，含启动、最终校验和归档，最终状态哈希一致。端到端提升约 4.7 倍；不同环境的收益会不同。

- 启动增加全屏加载页与真实资源进度条，代码及画面素材准备完成后进入菜单；继续使用原始高清素材，不额外压缩。加载失败保留原有素材回退；代码下载失败可点击重新加载。

回放引擎版本为 `2`；旧引擎 `1` 的记录保留原规则，不混入新规则。下载 `BombIt-v2.0.zip` 后可直接双击 `启动游戏.bat`，Agent 接入需要 Node.js 18+。
