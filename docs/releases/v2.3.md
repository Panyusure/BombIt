# v2.3 · 关前档案与状态牌可读性

关前敌情档案不再铺满整屏，字号整体调大；悬浮状态牌取消闪烁，危险信息只用稳定颜色表达。

## 关前敌情档案

- 卡片由 664×652 收到 608×552 并居中留边，四周露出战场，不再像整页替换。
- 字号整体上调：故事正文 9.3 → 10.4，敌情标题 19 → 21，行动/攻击说明 8.8 → 9.8，场景标题 24 → 26，开始按钮 18 → 19。
- 立绘改为按脚底定位：脚底压在黑色标签条上沿，水平严格居中，不再压住名字。
- 开始按钮命中区由 `BI.hud.briefingStart` 统一提供，渲染、输入与测试共用一套坐标。

## 悬浮状态牌

- 「第 N 关 / 剩余敌人」的整块和小字都不再闪烁；只剩 1–2 只敌人时小字固定橙色加粗。
- 计时拆砖最后 20 秒的「剩余障碍」同样改为稳定橙色。

## 修复

- 工厂传送带：敌人横向随带移动时不再在带边取消出口，可以正常走回地面。
- 截图工具 `tools/showcase.html` 新增 `briefing` / `briefing-boss` 场景，并等加载页退场后再摆位。
