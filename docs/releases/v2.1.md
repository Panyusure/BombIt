# v2.1 · 未来 PvP 充能

本版修正未来在双人对战中的充能缺口，并移除固定策略示例 Agent，让每个 Agent 由自己的模型通过 CLI 自行决策。

## 未来：迁境奇点

- 对战击倒对手同样直接充满通灵条；同帧双死时双方各充能一次。
- 对战通灵条改为**跨回合保留**，比赛开始时重置；冒险仍在换关时清空，同关阵亡重生保留。
- 选角页对战文案改为「每场放弹 6 次或击倒通灵」，单人保持「每关放弹 6 次或击杀通灵」。
- 技能说明、使用说明、技能与场景、角色背景、CLI 手册与设计测试覆盖同步更新。

## Agent 与示例

- 删除 `examples/` 及固定策略示例 Agent；仓库不再提供可被照搬的默认打法。
- Agent 由各自模型通过 `serve --memory` 观察 `state`，自行选择 `act/batch/path/goTo`，最后 `finish`。
- 更新 README、AGENTS.md、CLI 手册、npm scripts 与发布包清单；`npm test` 不再依赖示例 Agent 完整通关。
- 新增 CLI 集成测试：未来在 PvP 击倒对手后通灵条充满、跨回合保留；冒险换关仍清空。

## 验证

- 无头逻辑测试 953 项、CLI 测试 34 项、浏览器测试 498 项通过。
- 修改后由 DeepSeek Agent 使用未来完成 10 关冒险（种子 `demo`），回放通过命令行重演校验：
  - 10 / 10 关，346.6 秒游戏时间，2191 个动作，40 杀，130 次爆炸，8 次阵亡，最终 1 命。
  - 回放：`20261017-195135-deepseek-adventure-weilai-win-fe621e.replay.json`（本机 `data/replays/`，按 `.gitignore` 不纳入版本库）。

## 版本

游戏版本为 `v2.1`；引擎版本仍为 `2`，旧回放继续按原规则校验与播放。
