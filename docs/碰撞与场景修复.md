# 炸弹碰撞、传送带与场景调整

2026-10-16，根据最新反馈调整。

- 炸弹不再按整格 48×48 阻挡玩家。弹身半径 17 像素，玩家脚下半径 14 像素，两者实际相交才阻挡；保留近身挡路机制。移动炸弹的绘制和碰撞共用连续坐标，踢弹起步不会突然画到上一格，旧位置不残留阻挡。
- 原本已站在新放炸弹范围内的玩家可以先离开；离开后豁免结束。移动炸弹会在碰到角色时停下，不能直接挤入角色身体。炸弹偏离格心后仍可在真正接触的位置踢动。
- 右上角以爱心显示剩余生命，数量对应实际命数，单人最多五颗。双人对战每名存活玩家显示一颗，随本回合阵亡消失。
- 工厂传送带以 1.65 格/秒运送炸弹，沿闭环连续转弯。墙、障碍、其他炸弹和角色会阻挡运送；暂停时停止，时停期间敌弹的运输与引信一并冻结。怪物避险会保守考虑传送带可能运送炸弹到达的位置，避免炸弹追着投弹者移动导致自爆。
- 开局软障碍生成概率提高：闯关 72%、对战 66%、计时拆砖 74%，仅对可铺设格生效。只保留真正需要畅通的设施环道，其他区域可以铺设障碍。怪物优先出生于已有活动区，减少多余清场；仍保证两个空出口和至少十格活动空间。玩家出生区域保留两格退路。
- 鲁鲁旦回到 15×13 格的森林、工厂或游乐园常规地图，中央设施、环路、硬墙及可破坏障碍全部保留。仍为每五关一只、10 点生命；普通尺寸下每次释放六个单格毒叉，保留 1.3 秒预警和 1.8 秒持续时间。毒叉不落在软砖、硬墙和中央设施上。BOSS 血条放在最上方边界墙区域。
- 每关场景仍与前一关不同，包含 BOSS 关与离开 BOSS 后的下一关。

验证：669 项逻辑检查、240 项浏览器检查通过；持续运行检查覆盖五角色和普通/BOSS关卡，累计 1200 秒游戏逻辑时间，本次放置 976 颗玩家炸弹，无未处理异常。72 张开局地图在怪物出生后均保留至少 40 个可破坏障碍，另验证了 72 张 BOSS 地图仍保留三主题设施和障碍。已检查三个主题 BOSS 战和开局地图的实际画面。
