# Q版泡泡堂 · 使用说明

> 零安装、零联网。**双击 `启动游戏.bat`（推荐）或 `index.html`** 就能玩。

---

## 一、开始游戏

1. **双击 `启动游戏.bat`**（推荐）：加载完就有背景音乐，`F5` 刷新也一样
2. 或者直接双击 **`index.html`**（推荐 Chrome 或 Edge）：也能玩，只是浏览器不允许页面在用户交互前出声，音乐要等你点一下画面或按个键
3. 开始界面里选**模式**和**角色**
4. 按 `Enter` 开始，或者直接用鼠标点「开始游戏」

> 建议按 `F11` 全屏，画面会更大更舒服。

`启动游戏.bat` 只是用 `--autoplay-policy=no-user-gesture-required` 打开 Edge/Chrome，并给它一个独立的浏览器配置目录（不影响你平时那个浏览器窗口）；不想用启动器时，直接双击 `index.html` 一样能玩，区别只有音乐什么时候响。

六位精灵均使用高清透明素材。刷新或重新打开游戏即可加载；运行异常时可通过恢复菜单重开或返回。角色背景与未来的新机制见 [角色背景与文案](角色背景与文案.md)。

向上移动时显示角色背面，向下切回正面，向左或向右沿用左右朝向；松开方向键后保持最后朝向。未来通灵前后都有独立背面素材。背面仅改变外观，不改变碰撞范围和技能；素材未加载时自动使用正面，选角菜单仍展示正面。

## 二、操作键位

⚠️ **注意三点**：

1. **同一个 1P，在单人和双人模式下的放炸弹键是不一样的。** 这是规则要求，游戏里 HUD 上方也一直显示着当前模式的键位，按错了看一眼就知道。
2. **只能上下左右走，不能斜着走。** 同时按住两个方向时，走「后按下的那个」；松开一个立刻回到另一个，不会卡住。
3. **单人模式的移动键有两套：方向键和 `W` `A` `S` `D` 都能用**，随手指习惯挑一套，也可以混着按（松开其中一个、另一个还按着就继续走）。放炸弹始终是 `空格`，`WASD` 只负责移动。双人模式则不行 —— 那里 `WASD` 是 2P 的，1P 只能用方向键。

| 模式 | 玩家 | 移动 | 放炸弹 | 技能 |
|---|---|---|---|---|
| **单人**（闯关打怪 / 计时拆砖） | 1P | `↑` `↓` `←` `→` **或** `W` `A` `S` `D` | **`空格`** | **`Q`** |
| **双人**（同屏对战） | **1P** | `↑` `↓` `←` `→` | **`Enter`** | **右 `Shift`** |
| **双人**（同屏对战） | **2P** | `W` `A` `S` `D` | **`空格`** | **`F`** |

### 其他按键

| 按键 | 作用 |
|---|---|
| `Esc` / `P` | 暂停（弹出菜单）／在暂停菜单里再按一次直接继续 |
| `R` | 重开本局 |
| `Enter` / `空格` | 菜单确认、结算界面「再来一局」 |
| `Esc` / `M` | 结算界面「返回菜单」 |
| `Tab` | **切换 1P 备用键位**（见下方常见问题） |
| `M` | **静音 / 取消静音**（音效与背景音乐一起，对局中） |

> 菜单和结算界面**也可以直接用鼠标点**，不用记按键。

### 暂停菜单

按 `Esc` 或 `P` 会弹出暂停菜单，三件事都能做：

| 选项 | 快捷键 | 说明 |
|---|---|---|
| **继续游戏** | `Esc` / `Enter` | 回到对局 |
| **重新开始** | `R` | 本局从头再来（关卡和成长都会重置） |
| **返回菜单** | `M` | 回开始界面重新选模式 |

`↑` `↓` 选择，`Enter` 确认，鼠标直接点也行。暂停时战场完全冻结 —— 按方向键角色也不会动。

> 切到别的窗口（失焦）会**自动暂停并弹菜单**，切回来不会发现角色跑偏了。

## 精灵技能与随机场景

小诺、阿修、阿瑞、小炎、小天拥有主动技能：单人按 `Q`，双人1P按右 `Shift`、2P按 `F`，备用键位1P按 `O`。未来的“迁境奇点”为放弹被动，无需技能按键。技能栏位于左下角，双人2P位于右下角；暂停及关前介绍期间计时冻结。

| 精灵 | 技能 | 效果 | 冷却 |
|---|---|---|---|
| 小诺 | 时光星域 | 冻结怪物及敌方炸弹 3 秒；对战中使对手减速 | 12 秒 |
| 阿修 | 暗刃瞬袭 | 沿朝向突进最多三格，攻击沿途目标并短暂无伤；墙和炸弹会挡住突进 | 15 秒 |
| 阿瑞 | 森罗守护 | 获得一次性护盾，缠绕两格内可达怪物 2 秒；对战中使范围内对手减速 | 14 秒 |
| 小炎 | 炎灭火舞 | 4 秒内吸收一次爆炸，并把这次爆炸反弹给周围 5×5 内的敌人；不能抵挡毒叉或对战星星碰撞 | 12 秒 |
| 小天 | 潜能洞察 | 显示炸弹爆炸范围并增加 30% 移速，持续 6 秒 | 12 秒 |
| 未来 | 迁境奇点 | 放弹使3×3敌人减速45%·2秒；每关放弹6次**或击杀一只敌人**即通灵，强化为5×5减速75%·3秒 | 被动 |

主动技能临时效果在重生及换关时清除，普通道具成长保留。未来使用六格通灵条：每次成功放弹填充一格，**击杀任意一只敌人直接满条**（含 BOSS），两条路都能通灵；换关清空，同关重生保留。通灵附带双翼守护灵、轮廓光晕与觉醒动画。减速不改变怪物按原速度计算的逃生判断。技能设计依据见 [技能与场景说明](技能与场景.md)。

每局和每关随机进入**晨露森林、星汽工厂或星糖游乐园**，新一关一定与上一关不同。

| 场景 | 中央设施与玩法 | 可破坏障碍 |
|---|---|---|
| 晨露森林 | 3×3 格生命古树。开局 8 秒后首次落果，此后每 14 秒一次，地上最多两颗。拾取补一条命，最多 5 条；满命或双人对战改为一次护盾 | 木箱、倒木、蘑菇丛、幼树 |
| 星汽工厂 | 3×3 格反应炉，外围有 24 格顺时针闭环传送带。顺行加速、逆行减速、不按方向也随带移动；炸弹也随传送带运送，被挡住时停下 | 货箱、金属桶、能源罐 |
| 星糖游乐园 | 3×3 格旋转木马和 16 格环道，也会运送炸弹。松开方向搭乘完整一圈获得一次性护盾，每关限领一次；主动移动或离开环道会中断进度 | 礼物盒、气球篮、棉花糖摊 |

中央设施不可破坏，会挡住移动和爆炸。工厂与木马的环道保持畅通；古树周围按正常密度生成可破坏障碍，炸开后会腾出落果空地。果实和其他地面道具一样会被爆炸烧掉。不同外观的软障碍都可以用一次爆炸破坏。

传送带沿行进方向叠加 1.65 格/秒的速度，也以同样的带速运送炸弹并在转角沿环路继续前进；遇到墙、其他炸弹或角色时停下。木马搭乘速度为 1.8 格/秒。它们都遵守真实碰撞；暂停及关前介绍期间停止运行。木马奖励资格在换关时重置，本关阵亡重生不能重复领奖。

## 背景音乐与音效

三首曲子按场景自动切换，换曲时交叉淡入淡出（约 1.4 秒淡入 / 0.7 秒淡出），不会硬切：

| 场景 | 曲目 | 文件 |
|---|---|---|
| 开始界面 | 天空之城（八音盒版） | `assets\audio\纯音乐 - 天空之城 (八音盒版).ogg` |
| 关卡对局（计时拆砖、双人对战、冒险的普通关） | カノン（八音盒版） | `assets\audio\纯音乐 - カノン (八音盒版).ogg` |
| BOSS 战（第 5、10 关，鲁鲁旦还活着时） | 欢乐斗地主背景音乐 | `assets\audio\纯音乐 - 欢乐斗地主背景音乐 (Inst_).ogg` |

- 击败鲁鲁旦之后，哪怕场上还有小怪没清完，音乐也会换回カノン —— BOSS 倒了就不是 BOSS 战的气氛了。

- 按 `M` 一次性静音/取消静音，**音效和音乐一起**；暂停（`Esc` / `P`）或切出窗口时音乐停住，回来继续放。
- 结算界面继续放刚才那首，回到开始界面才换回天空之城。
- 音效仍然是实时合成的（不依赖任何音频文件），见 [设计方案 §5.6](设计方案.md)。
- **刷新后音乐就响**：用 `启动游戏.bat` 打开即可。直接双击 `index.html` 时，浏览器默认不允许页面在用户交互前出声，游戏会照常尝试播放，点一下画面或按个键就立刻响。
- 想换曲子：把新的 `.ogg` 放进 `assets\audio\`，改 `src\audio\music.js` 顶部 `TRACKS` 里的 `file`（路径相对项目根目录）与 `title`；`volume` 控制该曲音量。

## 三、三种模式怎么玩

### 1. 单人 · 闯关打怪

右上角用爱心显示剩余生命，每颗爱心代表一条命，随阵亡、过关补命和生命果实实时更新。开局障碍密度已提高，同时保留出生点的两格退路和怪物活动空间。

冒险共 **10关**。击败本关全部敌人后进入下一关；清完第10关最终战的鲁鲁旦和全部随从，即为冒险通关。

- 开局 **3条命**，最多 **5条命**。平时接触怪物无伤害；怪物拾取无敌星星后6秒内，碰撞会造成一次普通伤害。
- **过关保留火力 / 炸弹数 / 速度成长**，补 1 条命（最多 5 条），未消耗的护盾保留。
- 第1关谷谷歌歌，第2关加入克劳德德，第3关加入偶喷诶艾；第5关首次迎战鲁鲁旦，第10关为最终战。普通关最多五只怪物。
- 前5关保留教学与首次BOSS战节奏，后5关浓缩原后半程的敌人数量、移速与攻击欲望成长。关卡进度显示为“当前关／10”。
- 每关开打前可查看介绍，按 Enter、空格或点击确认后开始。

| 敌人 | 外观 | 攻击机制 |
|---|---|---|
| **谷谷歌歌** | 蓝色翅膀与三叉戟的灰色小恶魔 | 一格火力；提示 0.7 秒后放弹，再沿安全路线撤退 |
| **克劳德德** | 紫色翅膀与三叉戟的灰色小恶魔 | 一格火力；保持距离、谨慎布弹 |
| **偶喷诶艾** | 红色翅膀与三叉戟的灰色小恶魔 | 两格火力；投弹间隔更长 |
| **鲁鲁旦** | 青绿卷发、红眼、褶领和紫色悬浮舱 | 8点生命，带随从；试探→认真→暴走，仅吃到星星后有碰撞伤害 |

三种普通怪物使用你提供的参考形象清晰化素材，统一显示大小与碰撞范围。手持三叉戟仅是外观，普通怪物不会用它造成接触伤害。投弹前会检查完整逃生路线；初始每只一颗自己的炸弹，拾取道具可增加数量。普通关全场最多两颗敌方炸弹，BOSS 关最多四颗。敌人会索敌、炸开挡路障碍、争抢道具，随关卡提高更积极地追击和投弹。

BOSS 战使用与普通关相同的 **15×13 格三主题地图**，随机进入森林、工厂或游乐园。鲁鲁旦拥有 **8点生命**，第5关带两只随从，第10关带四只随从。

- **一 · 试探（8～7血）**：朝玩家移动并投弹，不使用毒叉。
- **二 · 认真（6～4血）**：移速提高25%，解锁毒刺；第五关施法间隔8～8.8秒。
- **三 · 暴走（3血及以下）**：切换怒火受伤外观，优先追击，投弹更频繁，第五关毒刺间隔6.4～7.2秒；带橙色裂纹标记的炸弹可以炸掉场内硬墙，逐步减少掩体。外围边界与中央设施保留。

血条显示当前阶段，切换时有文字和光圈提示；每场BOSS战从试探重新开始。每次毒刺随机选六个空地落点，金色预警 **1.5秒**，激活 **0.8秒**，仅伤害落点那一格。第10关认真阶段施法间隔7.2～8秒，暴走阶段5.76～6.56秒。

玩家与敌人的无敌星星都持续6秒，并获得普通碰撞伤害；护盾先抵挡一次并保护1.5秒，玩家自身无敌和重生保护均可抵挡，双方无敌时互不伤害。生命上限、右上角爱心与结算统计统一为最多5条，单次死亡只扣1条，满血果实转为护盾。

炸弹与无敌星星碰撞每次均造成1点伤害，受击后保护0.8秒；有护盾时先抵挡，破盾后保护1.5秒。护盾和无敌星星可以抵挡毒叉，小炎的吸火仅吸收爆炸。小诺会同时冻结毒叉预警与持续计时。击败鲁鲁旦会清除毒叉；第5关清完随从后进入第6关，第10关清场后显示“冒险通关”，保留生命、击败敌人数和用时统计，残留炸弹不会继续扣命。换关场景不会与前一关重复。

设定出处、攻击参数和清晰化素材说明见 [敌人与 BOSS](敌人与BOSS.md)。

### 2. 单人 · 计时拆砖

**180 秒内炸光所有软砖块**就赢。没有敌人，纯拼效率。

- 软砖更多（比别的模式密），时间比较紧
- 优先吃「火力」和「速度」，效率最高
- 时间快到的时候倒计时会变红闪烁

### 3. 双人 · 同屏对战

两个人一个键盘，**先得 2 分者获胜**。

- 一人一条命，一方被炸死对方得 1 分，然后**换一张新地图**开下一局
- **同一帧双方都被炸死** → 两边各得 1 分（不偏袒任何一方）
- **超过 90 秒没人死** → 进入「死亡加速」：地图上的软砖全部消失、引信变短，强制分出胜负

## 四、道具

软砖被炸掉后有 **30% 概率**掉道具，走过去就能捡。敌人被打死也有 45% 概率掉。

| 道具 | 效果 | 上限 |
|---|---|---|
| 🔥 **火** | 火焰长度 +1 格 | 8 格 |
| 💣 **弹** | 可同时放置的炸弹 +1 | 8 颗 |
| 👟 **速** | 移动速度 +10% | +50%（封顶） |
| 🛡️ **护盾** | 抵挡一次伤害后消失，并获得1.5秒保护；未消耗时可跨关保留 | 1 次 |
| ⭐ **无敌星星** | 无敌6秒，碰撞造成一次普通伤害；护盾先抵挡，BOSS每次扣1血，受击保护期间不重复受伤 | 重复拾取刷新至6秒 |
| 🧤 **推弹手套** | 接触炸弹可直线推动，受阻后停下，继续按原引信倒数 | 拾取后持续生效，可跨关保留 |
| 🦶 **踢** | 撞到炸弹能把它踢出去 | — |

> ⚠️ **地上的道具会被火焰烧掉！**（经典规则）所以看到道具要赶紧去捡，别让它被炸没。
> 反过来也能利用这一点——把对手想要的道具直接炸了。

推动不重置、暂停或延长炸弹引信。受阻后不会立即爆炸；若引信在滑行途中耗尽，就在当前位置爆炸。炸砖、火焰连锁和场景运送继续生效。右上角的手套图标表示已获得推弹能力。

## 五、小天的爆炸范围洞察

游戏里**默认不显示**爆炸范围和倒计时 —— 靠引信闪烁和手感判断。炸弹最后 0.6 秒会变红急闪，那就是"要炸了"的信号。

爆炸范围显示为小天「潜能洞察」专属效果，只在技能生效的 6 秒内显示。D 键没有威胁图功能，也没有面向所有角色的范围预览开关。双人 2P 的 D 键仍正常向右移动。

## 六、几个实用技巧

1. **刚放的炸弹自己能踩过去，但走出去就回不来了。** 这是经典规则，可以用来做"放完立刻绕路"的操作，也可以用来封自己的走位——小心别把自己关死。
2. **连锁引爆**：一颗炸弹的火焰碰到另一颗炸弹，那颗会**立刻**炸。把炸弹摆成串能炸出超长的一条通道。
3. **站在自己炸弹上放第二颗**是自杀，别按太快。
4. **记住引信的节奏**。默认 2.4 秒，最后 0.6 秒会变红急闪。使用小天的洞察技能可以短暂看清爆炸范围。
5. **道具会被烧掉**，看到就赶紧捡；对手想要的那颗，也可以直接炸了。
6. 小天的范围显示有冷却，适合在多颗炸弹或复杂连锁时使用。
7. **地图每局都不一样**。不可破坏的障碍按场景随机摆放，允许死胡同，但保证最终连通。
8. 卡住了或者觉得地图不好，按 `R` 换一张重开。

## 七、换成你自己的角色

游戏自带 5 个角色（小诺 / 阿修 / 阿瑞 / 小炎 / 小天）。想换的话：

1. 把你的角色图放进 **`aqcs\`** 文件夹
2. 跑一下抠图脚本：

   ```
   python tools\extract_characters.py --preview
   ```

   它会把角色从图里抠出来（透明背景）、裁好边、缩放好，输出到 `assets\characters\`，
   同时在 `_inspect\extracted.png` 给一张对比图让你检查效果。

3. 打开 **`assets\characters.js`**，照着已有格式加一条，填上名字、图片路径、显示高度和锚点。
   `height` 调大小，`anchor` 的第二个数对准**脚底**（角色飘起来就是它没调对）。
4. 刷新游戏即可。

> 没有导入素材也能玩：游戏会自动用几何占位小人，图片加载失败时也不会影响游戏。

## 八、常见问题

**Q：按方向键没反应 / 走着走着丢键？**
这是**键盘无冲（n-key rollover）**问题——便宜的键盘同时按 3 个以上键（尤其方向键）会丢掉一些键。双人同屏时最容易遇到，单人模式换 `WASD` 走通常也能绕开。
**按 `Tab` 可以把 1P 切到备用键位 `IJKL` 移动、`U` 放弹、`O` 技能**（单人模式下 `WASD` 依旧可用），和 2P 的 WASD 分得更开，基本就不会冲突了。

**Q：刷新后没有音乐？**
浏览器默认不允许页面在**用户交互之前**出声（自动播放策略），直接双击 `index.html` 时音乐要等你点一下或按个键。
想要刷新就有音乐，请用 **`启动游戏.bat`** 打开：它对 Edge/Chrome 带上 `--autoplay-policy=no-user-gesture-required`，加载完直接出声，`F5` 刷新也一样。
也可以自己在浏览器里放行：Edge → 设置 → Cookie 和站点权限 → 媒体自动播放 → 改成「允许」；Chrome → 设置 → 隐私和安全 → 网站设置 → 声音 → 把 `file://` 加成允许。
如果还是没有，看 HUD 左下角显示的是「音效开」还是「音效不可用」。对局中按 `M` 可以切换静音（音效与音乐一起）。音乐文件的格式是 Ogg Vorbis，Chrome / Edge 支持；换成别的浏览器可能只出声、不出乐。

**Q：切换窗口回来角色一直朝一个方向跑？**
不会。切出去时游戏会自动暂停并清空按键状态。

**Q：144Hz 屏幕会不会游戏变快？**
不会。逻辑固定跑 60Hz，和屏幕刷新率无关。

**Q：双击打不开 / 白屏？**
请用 Chrome 或 Edge 打开。如果浏览器太老可能不支持（需要近两年的版本）。

## 炸弹的实际碰撞

炸弹按实际弹身的位置阻挡玩家，使用圆形脚下范围与弹身范围相交判定，视觉上还隔着空隙时可以经过。移动炸弹的绘制和碰撞共用连续位置，不会在旧格子留下阻挡。自己或他人在脚下放下炸弹时，原先重叠的玩家可先离开，离开后不能再穿回炸弹。
